## 1. ภาพรวม

- เกม co-op ป้องกันฐานแบบ **ผู้เล่นสู้เองล้วน ๆ** (ไม่มีป้อม/สิ่งก่อสร้าง) ทีม **1–3 คน**
- ธีม **ยุคกลางแฟนตาซี** สไตล์ **กึ่งสมจริง**
- มุมกล้อง **third-person (shift-lock)** เล็งตามเมาส์ สลับอาวุธปุ่ม 1–5, รองรับมือถือ
- ไม่มี friendly fire

**Core loop:** Lobby → จัด loadout (12 แต้ม) → เข้าแมตช์ (1 stage = 5 wave) → ชนะ/แพ้ → เปิดหีบ (ชิ้นส่วน) + EXP → อัพเกรด / rank up ปลดล็อคของใหม่ → กลับ Lobby

---

## 2. Lobby (public area)

- ผู้เล่นเข้าเกมมาโผล่ที่ลานกลาง เดินเล่นกับเพื่อนได้
- ของใน lobby:
  - **หุ่นฝึก (training dummy)** — ลองอาวุธ เห็นตัวเลข damage
  - **กระดานอันดับ global Top 50** เรียงตาม EXP (OrderedDataStore) พร้อมไอคอน rank
  - **ป้าย rank ลอยบนหัว** ผู้เล่นใน lobby
  - จุด/ปุ่มเปิดหน้า **Loadout** (รวมการอัพเกรดไว้ที่นี่ — **ไม่มีโรงตีเหล็ก**)
- UI บนจอ: **Play**, **Invite**, **เลือก Stage**

### Party & Matchmaking
- ทีมสูงสุด **3 คน**
- **Invite:** ชวนผู้เล่นใน lobby เดียวกันได้โดยตรง + ชวนเพื่อน Roblox ผ่าน invite prompt (SocialService)
- **หัวหน้าทีมเลือก stage** ได้สูงสุดเท่าที่ตัวเองปลดล็อค (สมาชิกเล่น stage ที่ตัวเองยังไม่ปลดล็อคได้ ถ้าชนะก็ปลดล็อคให้ด้วย)
- กด **Play** ตอนทีมไม่ครบ → หาผู้เล่นจาก **ทุก lobby server** (MemoryStoreService queue) ที่เลือก **stage เดียวกัน** นาน **30 วินาที** → ไม่ครบก็เริ่มด้วยจำนวนที่มี
- หัวหน้าทีมกด **"เริ่มเลย"** เพื่อข้ามการหาคนได้
- เข้าด่านด้วย TeleportService ไป **reserved server** (place เดียวกัน แยกโหมดด้วย TeleportData หรือ place แยกใน universe เดียวกัน — ผู้พัฒนาเลือก)
- จบแมตช์ → หน้าสรุปผล + เปิดหีบ → teleport กลับ lobby

## 3. Loadout

- มี **12 แต้ม** จัดได้ **เฉพาะใน lobby** เข้าด่านแล้วล็อค
- ไอเท็มแต่ละอย่างเลือกได้ 1 ชิ้น (ยกเว้นที่ระบุ), **เกราะใส่ได้ 1 ชุดและใช้แต้มด้วย**
- ระบบ **จำ loadout ล่าสุด**; ถ้าไม่เคยจัด ใช้ชุดเริ่มต้น: ดาบ + ธนู + ลูกธนูเพิ่ม + เกราะหนัง + ยา = 12 แต้ม

### หน้าจอ Loadout
- การ์ดแต่ละไอเท็มแสดง **โมเดล 3D ของไอเท็มจริง (ViewportFrame) แบบนิ่ง ไม่หมุน** — ใช้โมเดลเดียวกับในเกม
- บนการ์ด: ชื่อ, **แต้ม**, **เลเวลอัพเกรด**, **แถบชิ้นส่วน** (เช่น 3/8), ปุ่ม **"อัพเกรด"** เมื่อชิ้นส่วนครบ
- ไอเท็มที่ยังไม่ปลดล็อค: สีเทา + รูปกุญแจ + บอก rank ที่ปลดล็อค
- แสดงแต้มที่ใช้ไป / 12

### ตารางไอเท็ม

| Rank ที่ปลดล็อค | ไอเท็ม | แต้ม | รายละเอียด |
|---|---|---|---|
| Bronze | ดาบ | 3 | คอมโบ 3 จังหวะ |
| Bronze | ธนู | 3 | มาพร้อมลูกธนู 6 ดอก, กดค้างง้าง |
| Bronze | ลูกธนูเพิ่ม | 2 | +6 ดอก (ซื้อซ้ำได้) |
| Bronze | โล่ | 2 | กดค้างคลิกขวาเพื่อกัน |
| Bronze | ยาฟื้น HP | 2 | ได้ 2 ขวด, **ซื้อได้ครั้งเดียว** |
| Bronze | เกราะหนัง | 2 | ลดดาเมจ 15% |
| Silver | หอก | 4 | ระยะตีไกล |
| Silver | เกราะโซ่ | 4 | ลดดาเมจ 30% |
| Gold | หน้าไม้ | 4 | แรงแต่ยิงช้า (ใช้ลูกธนู) |
| Gold | ค้อนสองมือ | 5 | |
| Platinum | ปืนคาบศิลา (Musket) | 4 | ยิงไกลแบบสไนเปอร์, คลิกขวาเล็งซูม, บรรจุ 3 วิ |
| Platinum | เกราะเหล็ก | 6 | ลดดาเมจ 45% |
| Legend | ดาบในตำนาน | 5 | |
| Legend | เกราะในตำนาน | 7 | |

ตัวเลขดาเมจ/ความเร็วของแต่ละอาวุธ: ผู้พัฒนากำหนดค่าเริ่มต้นแล้วปรับสมดุลผ่าน ConfigService

## 4. Rank & EXP

| Rank | EXP ขั้นต่ำ |
|---|---|
| Bronze | 0 |
| Silver | 500 |
| Gold | 1,500 |
| Platinum | 4,000 |
| Legend | 10,000 |

- Rank up → ปลดล็อคไอเท็มตามตารางข้อ 3
- **ตกแรงก์ไม่ได้**: EXP ลดได้ไม่ต่ำกว่าขั้นต่ำของ rank ปัจจุบัน, ของที่ปลดล็อคแล้วไม่หาย

## 5. รางวัล & อัพเกรด

| ผลแมตช์ | หีบ (ชิ้นส่วน) | EXP |
|---|---|---|
| ชนะ | 3–5 ชิ้น | +100 × เลข stage, ปลดล็อค stage ถัดไป |
| แพ้ | 1–2 ชิ้น | −40 × เลข stage (ไม่ตกแรงก์) |

- ทุกคนได้หีบของตัวเอง สุ่มแยกกัน
- **ชิ้นส่วนเป็นของเฉพาะไอเท็ม** (ชิ้นส่วนดาบใช้กับดาบเท่านั้น) สุ่มเฉพาะไอเท็มที่ **ปลดล็อคแล้ว**
- อัพได้ **5 เลเวล** ใช้ชิ้นส่วน **5 / 8 / 12 / 16 / 20** ชิ้น
- โบนัส **+3% ต่อเลเวล**: อาวุธ = ดาเมจ, เกราะ = HP สูงสุด
- อัพเกรดไม่เปลี่ยนแต้ม loadout
- ไม่มีเงินในเกม และไม่มี Robux/gamepass ใน MVP (ในอนาคตห้าม pay-to-win)

## 6. แมตช์ / ด่าน

- **1 แผนที่, 5 stage**; 1 แมตช์ = 1 stage
- แต่ละ stage มี **5 wave**, **wave 5 มี Boss**, พักระหว่าง wave **15–20 วินาที**
- Monster เข้ามา **ทางเดียวจากด้านหน้า** เดินไปยัง **คริสตัลเวทกลางป้อม (ฐาน) HP 1,000** — HP ฐานไม่ฟื้นระหว่าง wave

### เงื่อนไขแพ้
- **HP ฐาน = 0** หรือ
- **ผู้เล่นทั้งทีมล้มพร้อมกัน → แพ้ทันที**

### ปรับตามจำนวนผู้เล่น
- จำนวน monster ต่อ wave × **0.5 / 0.75 / 1.0** สำหรับ 1 / 2 / 3 คน
- HP Boss × จำนวนผู้เล่น

## 7. Monster

| Monster | HP | การโจมตี | เริ่มเจอ |
|---|---|---|---|
| Goblin | 60 | ฟันระยะประชิด 10 | Stage 1 |
| Skeleton Archer | 50 | ธนู 8, ระยะ 40 studs, **มีโอกาสดรอปลูกธนู** | Stage 2 |
| Orc Brute | 250 | ทุบ 25, ช้า, ตีฐานแรง | Stage 3 |
| Goblin Musketeer | 70 | ยิง 20, ระยะ 60 studs, ยิงทีละนัด บรรจุ 3 วิ | Stage 4 |
| **Boss: Orc Warlord** | 1,500 × จำนวนผู้เล่น | ฟันกวาดเป็นวง + เรียกลูกน้อง | Wave 5 ทุก stage (แข็งขึ้นตาม stage) |

### กติกาการเปลี่ยนเป้าหมาย (AI)
- เป้าหลัก = **ฐาน**
- เปลี่ยนไปตีผู้เล่นเมื่อ:
  - มีผู้เล่นอยู่ในระยะ **12 studs ข้างหน้า** (ขวางทาง)
  - **โดนผู้เล่นตี**
  - (monster ยิงไกล) **เห็นผู้เล่นในระยะยิง**
- กลับไปหาฐานเมื่อผู้เล่นตาย/ล้ม หรือหนีไกลเกิน **30 studs**
- **ไม่ตีผู้เล่นที่ล้มอยู่**
- **Boss** เลือกตีคนที่ทำดาเมจใส่ตัวเองมากที่สุด

## 8. การต่อสู้ของผู้เล่น

- ผู้เล่นมี **HP 100**
- **ดาบ:** คอมโบ 3 จังหวะ จังหวะที่ 3 แรงสุด
- **ธนู:** กดค้างง้าง ยิ่งง้างนานยิ่งแรงและบินไกล
- **ปืนคาบศิลา:** คลิกขวาเล็งซูม ยิงแล้วบรรจุ 3 วินาที
- **โล่:** กดค้างคลิกขวาเพื่อกัน
- **ยิงโดนหัว ×1.5** (ธนู หน้าไม้ ปืน)
- **กลิ้งหลบ (Q):** ระยะ ~**14 studs ใน 0.45 วิ** (ไกล/เร็วกว่าเดิน ~2 เท่า), **i-frame 0.3 วิแรก**, คูลดาวน์ **3 วิ**, ไม่มีระบบ stamina
- ลูกธนูไม่เติมเองระหว่าง stage (ได้เพิ่มจาก loadout หรือดรอปจาก Skeleton Archer)

### ล้ม & ชุบ
- HP 0 → **ล้ม (downed)**: คลานช้า ๆ ได้ โจมตีไม่ได้ monster ไม่ตี
- เพื่อนชุบด้วยการ **กดค้าง E 3 วินาที** ใกล้ตัว; ถ้าคนชุบโดนตี → ต้องเริ่มกดใหม่
- ฟื้นมามี **HP 30%**
- ไม่มีใครชุบ → **รอจนจบ wave** แล้ว respawn ที่ฐาน
- ทั้งทีมล้ม → แพ้ (ข้อ 6)

## 9. Feedback: ตัวเลข damage, เสียง, เพลง

### ตัวเลข damage
- ลอยขึ้นจากตัว monster แล้วจางหายใน ~0.8 วิ
- **เห็นเฉพาะตัวเลขของตัวเอง**
- **สีแดง** = damage ปกติ
- **สีเหลือง ตัวใหญ่ ×1.5 + เด้ง** = โดนหัว
- **ไม่มี hitmarker กลางจอ**
- ผู้เล่นโดนตี: ขอบจอแดงวาบ (ไม่มีตัวเลข)

### เสียง
- เสียงทั้งหมดจาก Creator Store
- **จังหวะต้องตรงกับท่าทาง**: ผูกกับ animation marker (KeyframeMarker) — วืดตอนดาบเหวี่ยง, เสียงโดนตอนดาเมจเกิดจริง, สายธนูตอนปล่อย
- ฝั่งตัวเองเล่นเสียงทันที (client-side) ไม่รอ server
- **เสียงยิงโดนหัวต้องดังและเด่นเป็นพิเศษ**
- เพลง: lobby / ต่อสู้ / boss แยกกัน

### Animation
- สร้างด้วย `generate_animation`: ดาบคอมโบ 3 จังหวะ, ง้าง/ปล่อยธนู, เล็ง/ยิงปืน, แทงหอก, ยกโล่, กลิ้งหลบ, ล้ม, คลาน, ชุบเพื่อน, ท่าโจมตี/ตายของ monster ทุกแบบ
- เดิน/วิ่ง ใช้ของ Roblox
- ต้อง **เหมือนจริง** — ถ้าท่าไหนไม่ผ่าน หาจาก Creator Store แทน

## 10. Milestones

แต่ละเฟสต้องเล่นทดสอบได้จริงก่อนไปเฟสถัดไป

1. **Combat core (1 คน):** แผนที่ + ฐาน, ดาบ, ธนู, Goblin wave, ตัวเลข damage, เสียง + animation, กลิ้งหลบ
2. **Match complete:** monster ครบทุกแบบ + Boss, 5 stage × 5 wave, ล้ม/ชุบ, เงื่อนไขแพ้/ชนะ, หน้าสรุปผล
3. **Progression:** Lobby, หน้า Loadout (ViewportFrame), DataStore (EXP, rank, ชิ้นส่วน, เลเวล, loadout ล่าสุด, stage ที่ปลดล็อค), หีบรางวัล, อัพเกรด, rank up
4. **Multiplayer:** Party/Invite, matchmaking ข้าม server (MemoryStore), teleport reserved server, ทีม 3 คน
5. **Polish:** เพลง, กระดานอันดับ global, ป้าย rank, รองรับมือถือ, ปรับสมดุลผ่าน ConfigService

## 11. นอกขอบเขต MVP (ไว้ทีหลัง)

- ป้อม/กับดัก/สิ่งก่อสร้าง
- หลายแผนที่, ทางเข้า monster หลายทาง
- Gamepass / ของขาย (ห้าม pay-to-win)
- เงินในเกม
